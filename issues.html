Resolved findings — original high severity

ISS-001 · /budgets

Malformed budget values are silently ignored while other rows are saved

High
Reproduction
In July budgets, change Cloud Services to abc, change Security Review to 55,000, then select Save Budgets.
Actual
The page redirects without an error. Cloud Services silently reverts to ₹1,20,000.00 while Security Review is saved as ₹55,000.00.
Expected
Reject the entire submission, identify the invalid row, preserve all entered values, and perform no partial accounting update.
Risk
Users can believe a complete budget plan was saved when only part of it changed.
ISS-002 · /?month=…

High
Reproduction
Open July without filters, then open the same grid with q=Cloud.
Actual

Expected
Close readiness must always use full-month counts, independent of presentation filters.
Risk
A filtered view can make an unready month appear safe to close.
