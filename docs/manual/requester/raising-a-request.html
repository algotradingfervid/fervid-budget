Manual / Raising requests

Raising a request

Filling in the form and sending it for approval, field by field.

Once you have picked a type, the second screen is the request itself. It is one form, one button, and one act: there is no draft to save and come back to. Pressing Submit request creates the request, gives it its number and sends it to your approver, all at the same moment.

The form, top to bottom

Every fieldset is the same on every type except two: the block under What is this for, which follows your treatment choice, and the type's own block — Vendor and invoice, Vendor and advance, Your expense or Advance details. A red asterisk marks the fields the product will insist on.

What is this for

FieldWhat it is for
Short titleRequiredOne line naming the spend. The hint says what it is for: What your approver will see in their approval list.
How should this be treatedRequiredTwo radio buttons — Budget expense or Refundable or recoverable. Changing it changes the next fieldset. See Budget spend or money you expect back.

Charge it to

FieldWhat it is for
ProjectRequiredThe project the spend belongs to. Choosing one narrows the Head list below to that project’s own heads.
HeadRequiredThe budget line the spend is booked against. Options read Project / Head, so you can see which project a head belongs to.

This fieldset only appears on a Budget expense. Choose Refundable or recoverable and it is replaced by Recoverable details — a category, an expected return date and the repayment terms.

Amount and timing

FieldWhat it is for
AmountRequiredThe figure you are asking for, typed without the ₹ — the field draws its own. Before you type, the line beneath reads Enter the amount you are requesting; once you do, it spells the figure out in words.
Needed byOptionalA date. The hint says Optional. It tells your approver how long they have.
Mark this urgentOptionalA checkbox. Ticking it reveals Why is it urgent, which is then required. See Marking a request urgent.

Purpose and documents

FieldWhat it is for
PurposeRequiredA free-text box. This is where you explain the spend to somebody who was not in the conversation.
Supporting documentOptionalOne file. The uploader says Add invoice, receipt or proof and, beneath, PDF, JPG or PNG up to 10 MB — the size is a figure your administrator sets. See Attaching documents.

Supporting document is marked optional here because this organisation has not made documents compulsory. Where an administrator has switched that on, the label carries a red asterisk instead and a further field appears asking you to say why, if you cannot attach one.

Who approves it

FieldWhat it is for
ApproverRequiredThe person who will decide. Your own default is already selected and marked (your default). The hint says You cannot approve your own request. Your own name is never in this list.

Beside it sits Reminders, which is not a control but a statement of what happens if nobody acts: If nothing happens for 3 days, this request starts sending a reminder every day to whoever it is waiting on. Both numbers are settings, so yours may read differently.

Submitting

  1. Fill in every field carrying a red asterisk.
  2. Attach the invoice, receipt or proof if you have one.

    You can add more documents later while the request is still editable.

  3. Check the Approver is the right person.
  4. Select Submit request.

    The note beside the button says what that does: Submitting sends it to your approver and creates the request number.

You land on a confirmation screen. It leads with Submitted., followed by your approver's name and has been notified. It shows the request's new number and amount, and lays out What happens next in three steps: your approver reviews it, Accounts picks it up once approved, and it settles. The buttons at the foot are Raise another, My requests and View this request.

Nothing is saved until you submit

There is no draft. Nothing you type is stored until you press Submit request, so do not leave the form half-filled and expect to come back to it. If you close the tab, you start again.

When the form comes back

If something is missing or contradictory, the form returns with a red band across the top carrying one sentence — the first problem it found. Everything you had already typed is still there; you are never made to fill the page in twice.

Every one of these rules is enforced on the server, not only in the browser. Hiding a field or switching one off in the page does not get a request past them.

The duplicate warning

When you leave the Amount field — and, on a vendor invoice, the Invoice number field — the product quietly looks for requests that resemble this one: the same payee, and either an amount within about one per cent or the very same invoice reference, raised in the last thirty days. If it finds any, a warning appears above the buttons listing them, saying Same payee and a close amount in the last 30 days. Check before you submit — you can still go ahead.

The warning never blocks you. Repeat payments are real — the same rent, the same monthly retainer — so the product points and you decide.

The request number

The number is issued at submission and never changes afterwards. In this organisation it is shaped PR-2026-000426: a prefix, the year, and a running count. Editing a request keeps its number; withdrawing it keeps it; only raising a brand-new request produces a new one.

Can I save this and finish it tomorrow?

No — there are no drafts. Either submit it, or raise it again tomorrow from scratch. A submitted request can still be edited while it is awaiting approval, so submitting early is usually the safer choice.

The Head list is empty.

Choose a Project first. The head list narrows to the heads belonging to the project you named, and only heads that are still open appear at all.

My approver is not in the list.

The list holds only active people who are allowed to approve, and never you. If the person you want is missing, ask an administrator to give them the approver role.

I typed ₹ in the amount and it was refused.

The field draws its own ₹ symbol at the left. Type the figure only.
