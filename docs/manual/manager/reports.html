Manual / Approving

Reports

Compare budgets and actual payments, then inspect the records behind the figures.

Choose a view and range

Monthly has one row per month, Projects one project per month, and Heads one expense head per month. Set From and To, then Run. The heading and any Showing context identify the exact date and project/head scope of the displayed totals.

Read and follow the figures

Budget is planned spend; Actual is active budget payments, including recorded installments. Remaining is Budget minus Actual, and Used is Actual as a percentage of Budget. Recoverable deposits and voided payments are excluded. Approval alone is not an actual payment.

  1. Use View projects on a monthly row to inspect that month.
  2. Use View heads on a project row to inspect its heads.
  3. Use View budget and payments on a head to see its period and supporting records.
  4. Use View budget or Open payment where your permissions allow.
  5. Use Back to source report or the context back link to restore the exact prior report range and filters.

Underlying payment records need separate payment access. The payment section explicitly states its limit of the latest 300 records per month and your data scope; a restricted user can see fewer payments than the overall report total.

Retaining context

Changing From/To within a head or project drilldown retains that selection. The source-report link retains the original range. Current month changes the date range while retaining the selected project/head and the source-report back link. A selected period with no activity still shows its context and zero figures. The monthly tab returns to the broader monthly comparison.

Exporting

CSV export appears only with export permission. A scoped drilldown labels its download Export full … report CSV because the export covers the full grouping for the selected dates, not just the selected project or head. Ask an authorised colleague for exports you cannot access.
