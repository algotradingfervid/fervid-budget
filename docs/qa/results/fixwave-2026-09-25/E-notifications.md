# Fix wave 2026-09-25 — cluster E (notifications)

One row per defect. Every fix was reproduced first with a test that failed on
the old code, and then checked in the browser against a fresh seeded server with
an SMTP sink that offers 8BITMIME but not SMTPUTF8. The browser runs used 1440 px
and 390 px viewports.
