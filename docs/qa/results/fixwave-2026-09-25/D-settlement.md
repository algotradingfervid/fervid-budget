# Fix wave 2026-09-25 — cluster D (settlement)

Eleven confirmed defects in reservation, settlement and the partial review.
Every one was reproduced by a Go test written before the fix (each failed
against the code as it was), fixed at its root cause, and then driven from the
frontend with Playwright at 1440 px and 390 px against a freshly seeded server
built from this branch; every user, request, approval and payment in that run
was created through the app's own forms.

Owner decisions applied: no new status for settlement-8 (a flag on the row,
read by the display); every settlement notification names the amount paid and
the approved figure; the request detail gets "Record payment" for Accounts.
